## 1. Какво е компонент в Angular?

В Angular, **компонентът (Component)** е основният градивен блок на потребителския интерфейс (UI). Всяко Angular приложение се състои от дърво от компоненти. Можете да мислите за компонента като за персонализиран, капсулиран HTML елемент, който съдържа собствена структура, стил и поведение.

Ако в чистия уеб дизайн използвате тагове като `<header>`, `<nav>` или `<div>`, в Angular вие създавате свои собствени тагове – например `<app-user-profile>` или `<app-shopping-cart>`.

Всеки компонент в Angular се състои от три неразделни части:

1. **TypeScript клас (Логика):** Тук се дефинират данните (свойства/променливи) и поведението (методи/функции) на компонента.
2. **HTML темплейт (Изглед):** Определя структурата на това, което потребителят вижда на екрана.
3. **CSS/SCSS стилове (Дизайн):** Дефинира външния вид. Специфичното тук е, че стиловете са *капсулирани* – те важат само за конкретния компонент и не "изтичат" към други части на приложението.

За да превърнем един обикновен TypeScript клас в Angular компонент, използваме **декоратора `@Component**`. Декораторите са функции, които добавят метаданни към класовете (подобно на анотациите в Java).

## 2. Създаване на прост компонент

Най-лесният начин да създадете компонент е чрез интерфейса на командния ред на Angular (Angular CLI). Отворете терминала в директорията на вашия проект и изпълнете:

```bash
ng generate component greeting
# или кратката версия:
ng g c greeting

```

Тази команда ще създаде папка `greeting` с четири файла (HTML, CSS, TypeScript и файл за тестове `.spec.ts`). Нека разгледаме генерирания TypeScript клас (`greeting.component.ts`):

```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-greeting',
  templateUrl: './greeting.component.html',
  styleUrls: ['./greeting.component.css']
})
export class GreetingComponent {
  // Тук пишем нашата логика
  title: string = 'Добре дошли в Angular!';
  
  changeTitle() {
    this.title = 'Заглавието е променено!';
  }
}

```

* **`selector`**: Това е името на персонализирания HTML таг, който ще използваме, за да вмъкнем този компонент другаде (напр. `<app-greeting></app-greeting>`).
* **`templateUrl`**: Пътят до HTML файла на компонента.
* **`styleUrls`**: Масив от пътища до CSS файловете.

## 3. Обвързване на данни (Data Binding)

Една от най-мощните характеристики на Angular е **обвързването на данни (Data Binding)**. Това е механизмът, който автоматично синхронизира данните между TypeScript класа (логиката) и HTML темплейта (изгледа).

Без Data Binding, в чист JavaScript (Vanilla JS), щеше да се налага ръчно да търсите елементи с `document.getElementById()`, да добавяте `addEventListener` и изрично да обновявате `innerHTML`. Angular прави всичко това автоматично чрез четири основни типа обвързване.

### 3.1. Интерполация (Interpolation) `{{ }}`

*Посока: От Класа към Темплейта (One-way)*

Интерполацията се използва за визуализиране на текстови данни от класа директно в HTML-а. Използва се синтаксисът с двойни фигурни скоби (често наричан "мустаци").

**TypeScript:**

```typescript
export class UserComponent {
  firstName: string = 'Иван';
  age: number = 21;
}

```

**HTML:**

```html
<p>Здравей, аз съм {{ firstName }} и съм на {{ age }} години.</p>

```

*Забележка:* В рамките на `{{ }}` можете да пишете и прости JavaScript изрази, например `{{ age + 1 }}` или `{{ firstName.toUpperCase() }}`.

### 3.2. Обвързване на свойства (Property Binding) `[ ]`

*Посока: От Класа към Темплейта (One-way)*

Докато интерполацията работи добре за текст, **обвързването на свойства** се използва за контролиране на DOM свойствата на HTML елементите (като `src`, `href`, `disabled`, `value`, класове и стилове). Използват се квадратни скоби `[ ]`.

**TypeScript:**

```typescript
export class ButtonComponent {
  imageUrl: string = 'https://example.com/logo.png';
  isButtonDisabled: boolean = true;
}

```

**HTML:**

```html
<img [src]="imageUrl" alt="Лого">

<button [disabled]="isButtonDisabled">Запази</button>

```

*Важно отличие:* `[disabled]="true"` манипулира директно DOM свойството (property) на елемента в паметта на браузъра, а не просто HTML атрибута (attribute).

### 3.3. Обвързване на събития (Event Binding) `( )`

*Посока: От Темплейта към Класа (One-way)*

Как можем да реагираме на действията на потребителя, като кликване, въвеждане на текст или преместване на мишката? Използваме **обвързване на събития** чрез кръгли скоби `( )`. Когато събитието настъпи, Angular извиква посочения метод в TypeScript класа.

**TypeScript:**

```typescript
export class CounterComponent {
  counter: number = 0;

  increment() {
    this.counter++;
  }
}

```

**HTML:**

```html
<p>Текуща стойност: {{ counter }}</p>
<button (click)="increment()">Увеличи</button>

```

### 3.4. Двупосочно обвързване (Two-Way Binding) `[( )]`

*Посока: Двупосочно (Клас ↔ Темплейт)*

Двупосочното обвързване е комбинация от Property Binding `[ ]` и Event Binding `( )`. Затова синтаксисът му е `[( )]` – често наричан шеговито „банан в кутия“ (banana in a box).

То се използва най-често при работа с формуляри (`<input>`, `<select>`, `<textarea>`). Ако промените стойността в класа, инпут полето се обновява. Ако потребителят въведе текст в инпут полето, стойността в класа се обновява автоматично в реално време.

*Важно:* За да използвате `[(ngModel)]`, трябва първо да импортирате `FormsModule` във вашия основен модул (`app.module.ts` или директно в standalone компонента).

**TypeScript:**

```typescript
export class ProfileComponent {
  username: string = 'student123';
}

```

**HTML:**

```html
<label>Потребителско име:</label>
<input type="text" [(ngModel)]="username">

<p>Вие въвеждате: {{ username }}</p>

```

### Интерактивна симулация на Data Binding

За да разберете по-добре как работят тези четири механизма и как данните се движат между "Класа" (Логиката) и "Темплейта" (Изгледа), по-долу е предоставена интерактивна симулация. Можете да променяте стойностите чрез контролите и да наблюдавате как те влияят на състоянието на променливите в реално време.
