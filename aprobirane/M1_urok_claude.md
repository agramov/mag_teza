# Компоненти и обвързване на данни (data binding) в Angular

**Дисциплина:** Уеб програмиране с JavaScript рамки
**Формат:** Електронен урок за самостоятелна подготовка

## Учебни цели

След този урок ще можете да:

1. обясните какво представлява компонентът в Angular и от какви части се състои;
2. създадете прост собствен компонент;
3. прилагате четирите вида обвързване на данни — интерполация, обвързване на свойства, обвързване на събития и двупосочно обвързване.

---

## 1. Какво е компонент?

Angular е **компонентно-ориентирана** рамка. Това означава, че целият потребителски интерфейс се изгражда от малки, самостоятелни и преизползваеми градивни блокове, наречени **компоненти**. Можете да мислите за компонента като за парче от страницата, което има собствен външен вид и собствено поведение — например бутон за навигация, форма за вход или списък с продукти.

Всеки компонент се състои от **четири части**:

- **Клас (TypeScript)** — сърцето на компонента. Тук се съхраняват данните (свойства) и логиката (методи).
- **Шаблон (HTML)** — определя какво вижда потребителят на екрана.
- **Стилове (CSS)** — оформлението, което важи само за този компонент (така стиловете не се смесват с останалите).
- **Метаданни (декоратор `@Component`)** — специална анотация, която казва на Angular „това е компонент" и свързва класа с неговия шаблон и стилове.

Ключовото свойство в метаданните е `selector`. То дефинира името на HTML етикета, чрез който ще вмъкваме компонента в други шаблони. Ако `selector` е `app-greeting`, ще използваме компонента с етикета `<app-greeting></app-greeting>`.

---

## 2. Създаване на прост компонент

Ето минимален пример за компонент, който показва поздрав:

```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-greeting',
  standalone: true,
  template: `<h1>Здравей, {{ name }}!</h1>`,
  styles: [`h1 { color: navy; }`]
})
export class GreetingComponent {
  name = 'свят';
}
```

Нека разгледаме кода ред по ред:

- `import { Component }` внася декоратора `@Component` от ядрото на Angular.
- `@Component({ ... })` е декораторът с метаданните. Тук `selector` задава етикета, `standalone: true` означава, че компонентът е самостоятелен и не изисква модул, `template` съдържа HTML-а, а `styles` — CSS-а.
- `export class GreetingComponent` е класът на компонента. Свойството `name` е обикновена променлива, до която шаблонът има достъп.

> **Съвет:** В реални проекти шаблонът и стиловете често се разделят в отделни файлове чрез `templateUrl` и `styleUrls`, за да е кодът по-четлив. За малки примери ги пишем директно (inline), както по-горе.

За да видим компонента на екрана, го вмъкваме в шаблона на друг компонент (например главния):

```html
<app-greeting></app-greeting>
```

Резултатът ще бъде: **Здравей, свят!**

## 3. Обвързване на данни (data binding)

**Обвързването на данни** е механизмът, чрез който Angular синхронизира данните от класа на компонента с шаблона (изгледа) и обратно. Благодарение на него не се налага ръчно да търсим елементи в DOM и да ги обновяваме — Angular прави това автоматично.

Има четири основни вида обвързване. Удобно е да ги групираме според **посоката** на движение на данните:

| Вид | Синтаксис | Посока |
|-----|-----------|--------|
| Интерполация | `{{ израз }}` | клас → изглед |
| Обвързване на свойства | `[свойство]="израз"` | клас → изглед |
| Обвързване на събития | `(събитие)="метод()"` | изглед → клас |
| Двупосочно обвързване | `[(ngModel)]="свойство"` | клас ↔ изглед |

### 3.1. Интерполация

Интерполацията е най-простият начин да покажем стойност от класа в шаблона. Използваме двойни къдрави скоби `{{ }}`, вътре в които слагаме израз на TypeScript. Angular изчислява израза и вмъква резултата като текст.

```typescript
export class ProductComponent {
  productName = 'Лаптоп';
  price = 1499;
}
```

```html
<p>Продукт: {{ productName }}</p>
<p>Цена с ДДС: {{ price * 1.2 }} лв.</p>
```

Обърнете внимание, че вътре в скобите може да има и прости изрази (`price * 1.2`), не само имена на свойства. Интерполацията винаги извежда **текст**.

### 3.2. Обвързване на свойства (property binding)

Когато искаме да зададем стойност не на текстовото съдържание, а на **свойство на HTML елемент или на друг компонент**, използваме квадратни скоби `[ ]`. Това се нарича обвързване на свойства.

```typescript
export class ProfileComponent {
  imageUrl = 'https://example.com/avatar.png';
  isButtonDisabled = true;
}
```

```html
<img [src]="imageUrl" alt="Профилна снимка">
<button [disabled]="isButtonDisabled">Изпрати</button>
```

Тук стойността на `src` идва динамично от свойството `imageUrl`, а бутонът ще бъде неактивен, защото `isButtonDisabled` е `true`.

**Внимание:** Разликата между `src="imageUrl"` и `[src]="imageUrl"` е съществена. Без скоби Angular ще приеме буквалния текст `"imageUrl"`. Със скоби Angular изчислява израза и взима стойността на свойството.

### 3.3. Обвързване на събития (event binding)

Дотук данните течаха от класа към изгледа. Обвързването на събития прави обратното — позволява на изгледа да **реагира на действия на потребителя** (щракване, натискане на клавиш, въвеждане и т.н.) и да извика метод от класа. За целта поставяме името на събитието в **кръгли скоби** `( )`.

```typescript
export class CounterComponent {
  count = 0;

  increment() {
    this.count = this.count + 1;
  }
}
```

```html
<p>Брояч: {{ count }}</p>
<button (click)="increment()">Увеличи</button>
```

При всяко щракване върху бутона се извиква методът `increment()`, стойността на `count` нараства и интерполацията автоматично обновява показаното число.

### 3.4. Двупосочно обвързване (two-way binding)

Двупосочното обвързване комбинира обвързване на свойство и обвързване на събитие в един израз. То се използва най-често при **форми**: стойността на полето отразява свойството от класа, а всяка промяна на полето от потребителя веднага обновява свойството.

Синтаксисът е `[(ngModel)]` — квадратни скоби (данни навътре) и кръгли скоби (данни навън), заедно. Помага мнемониката „**кутия в банан**" (`[()]`).

За да работи `ngModel`, трябва да внесем `FormsModule`:

```typescript
import { Component } from '@angular/core';
import { FormsModule } from '@angular/forms';

@Component({
  selector: 'app-form',
  standalone: true,
  imports: [FormsModule],
  template: `
    <input [(ngModel)]="username" placeholder="Име">
    <p>Здравей, {{ username }}!</p>
  `
})
export class FormComponent {
  username = '';
}
```

Докато потребителят пише в полето, параграфът под него се обновява в реално време. Това е възможно, защото данните текат в **двете посоки** едновременно.

## 4. Обобщение

- Компонентът е основният градивен блок в Angular и се състои от клас, шаблон, стилове и метаданни (`@Component`).
- Селекторът дефинира етикета, чрез който вмъкваме компонента другаде.
- Обвързването на данни синхронизира класа и изгледа. Четирите вида са:
  - **интерполация** `{{ }}` — извежда текст (клас → изглед);
  - **обвързване на свойства** `[ ]` — задава свойство (клас → изглед);
  - **обвързване на събития** `( )` — реагира на действия (изглед → клас);
  - **двупосочно обвързване** `[(ngModel)]` — комбинира двете (клас ↔ изглед).

Ключът към разбирането е **посоката** на данните. Ако запомните коя скоба в коя посока движи данните, ще избирате правилния вид обвързване без колебание.

```html

<input [(ngModel)]="email">
```

**Задача 3 (код).** Създайте компонент `TemperatureComponent` с числово свойство `celsius = 25`. В шаблона изведете чрез интерполация температурата и я преобразувайте във Фаренхайт по формулата `celsius * 9 / 5 + 32`.

**Задача 4 (код).** Добавете към компонента от Задача 3 бутон, който при щракване увеличава `celsius` с 1. Кой вид обвързване ще използвате за бутона?
